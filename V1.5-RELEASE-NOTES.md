# Food Passport v1.5

## Database
- Districts: 64
- Total food experiences: 330
- New source-backed entries in v1.5: 31
- New community-curated regional entries in v1.5: 76
- Source-checked total: 143

`Source checked` means a public reference is attached to the district-food association. It is not a GI/government certification. `Community curated` entries are regional food-culture additions and are labeled separately in the UI.

## Major V1.5 features
- 300+ searchable food experiences
- Wikimedia Commons runtime image resolver
- photo lookup cache in localStorage
- exact / Commons result / representative-photo distinctions
- district food-cover strip
- Taste Tier / Level system
- source provenance badge on every food
- premium share-card badge now includes Taste Tier
- V1.4 premium design, 64-district SVG map and desktop scrolling retained

## Runtime photo behavior
1. Hard-coded exact photo if available.
2. Otherwise search Wikimedia Commons using the food's `photo_query`.
3. Cache a successful result locally.
4. If Commons has no suitable result or the request fails, show a clearly-labelled representative photo.

This gives broad photo coverage without pretending that a fallback photo is an exact food image.
