# Food Passport v1.4 — Premium Atlas

## Database
- Districts: **64**
- Food experiences: **223**
- Source-checked entries: **112**
- Exact-photo entries currently in JSON: **14**
- Added in this release: **81** new source-backed entries

Sources used for this expansion include DBC News, Kuhudak, Unseen Bangladesh and Mati News. "Source checked" means the district-food association has a linked public reference in the dataset; it is not a government/GI certification.
